# 飞书网页与小程序对齐验收表

本表跟踪网页功能对齐与验收，不代表生产部署、真实授权或通知送达已验收。微信与飞书账号不会自动合并；群身份仍通过平台可信入口建立。

## 对照范围

| 模块 | 对齐目标 | 验收重点 |
|---|---|---|
| 群首页 | 群列表、周期、同步状态、说明 | 个人用量不混入首页；空群有真实加入指引 |
| 群详情 | 双榜、分页、本人排名、群分析、改名、显隐、退出、PK | 非成员拒绝、快照409、不公开临时PK |
| 广场 | 双榜、双环图、完整分析、趋势榜 | 本人资料直达可用；分类人数和Token口径不同 |
| 我的 | 同周期走势、活跃天数、工具模型、缓存分量 | 周期统计不混入历史累计 |
| 日历 | 13周、区间概览、设备/模型/费用设置、日期操作 | 缺记录/零值/未来不同；私有费用不默认公开 |
| 日报/周报 | 日期、峰值、主力摘要、群成绩、环比 | zero_base不等于缺记录；自然日/自然周用北京时间 |
| 分析 | 占比/趋势/明细、常用人数、下钻、用户分页 | 缺记录不断言零；覆盖率、重叠真实说明 |
| 订阅账本 | 订阅、充值、校准、成本/回本 | 仅本人；金额单位正确；不收集真实API密钥 |
| 接入 | 安装命令、AI指引、版本/设备/健康、重置 | 凭证不进URL/公开分享；重置需确认 |
| 资料/隐私 | 昵称头像、全局排名、群内显隐、注销 | 自定义资料不被OAuth覆盖；停用账号不得写入 |
| 分享 | 匿名读取、复制/系统分享、图片、撤销、PK | 公开字段白名单；过期/撤销复核；成本显式公开 |
| 成就 | 图鉴、卡片、档位、重播、首次展示、图片分享 | 图片动画完成才确认；离页释放；减少动态效果 |
| 消息提醒 | 飞书下一次日报/一次同步异常、启用取消 | 身份推导收件人；微信渠道隔离；超时不盲重试 |

## 平台适配原则

- 小程序原生转发与微信入口码改为网页链接、网页二维码和浏览器可用的系统分享/图片下载；不承诺飞书原生富卡预览。
- 微信群识别不移植为信任URL参数；网页无法自行建立群关系。
- 飞书提醒只发送用户明确预约的一次通知，不承诺永久每天推送。API接受消息不等于用户已读。
- 资料、账本、接入凭证、提醒和临时PK保持私有；公开页只使用服务端已校验的快照。
- API错误、未配置能力和无数据状态要说明原因与下一步，禁止仅放可点但无操作的按钮。

## 验证层次

1. 单元与接口测试：合成数据、mock消息transport、迁移幂等和旧数据保留。
2. 本地浏览器：真实Worker与独立SQLite，390/400px及桌面，点击所有关键路径；不使用线上凭证。
3. 客户端验收：真实飞书OAuth、客户端图片/分享兼容、消息权限与送达；需单独执行。
4. 发布：代码推送、数据库迁移、服务部署分别记录，不因测试通过自动执行生产动作。

每次交付须如实列出已验证项目、外部条件待验证项目和未完成项目，不能把入口存在当成功能全量完成。
